# משפט יומי בוואטסאפ

מערכת ששולחת כל יום, בשעה אקראית בתוך חלון שהמשתמש מגדיר, משפט של אהבה, הוקרה או השראה בוואטסאפ, ולומדת מהדירוגים.

## מצב

- שלב א (משתמש אחד): בבנייה.
- שלב ב (מוצר לכל אחד): מתוכנן. מבנה הנתונים כבר מוכן לריבוי משתמשים.

## רכיבים

| רכיב | תפקיד |
| --- | --- |
| Make | תזמון, שליחה, קליטת תגובות (שלב א) |
| Green API | חיבור למספר הוואטסאפ האישי |
| Supabase | מסד נתונים והתחברות משתמשים |
| Vercel | אירוח הממשק |

## מבנה המאגר

- `supabase/schema.sql`: מבנה הנתונים. מריצים פעם אחת בעורך ה-SQL של Supabase.

## אבטחה

מפתחות (Supabase, Green API, מנוע AI) לא נשמרים בקוד. הם מוגדרים כמשתני סביבה ב-Vercel וכחיבורים ב-Make.
