# משפט יומי בוואטסאפ

מערכת ששולחת כל יום, בשעה אקראית בתוך חלון שהמשתמש מגדיר, משפט של אהבה, הוקרה או השראה בוואטסאפ, ולומדת מהדירוגים.

## מצב

- שלב א (משתמש אחד): השליחה היומית עובדת, והממשק בגרסה ראשונה.
- שלב ב (מוצר לכל אחד): מתוכנן. מבנה הנתונים כבר מוכן לריבוי משתמשים.

## רכיבים

| רכיב | תפקיד |
| --- | --- |
| Supabase | מסד נתונים, התחברות משתמשים, ולוגיקת השליחה (פונקציות SQL) |
| Vercel | אירוח הממשק |
| Make | מפעיל את השליחה פעם בשעה (שלב א) |
| Green API | חיבור למספר הוואטסאפ האישי |

## מבנה המאגר

| קובץ | תוכן |
| --- | --- |
| `index.html`, `styles.css`, `app.js` | הממשק: הגדרות, מאגר משפטים, היסטוריה ודירוג |
| `api/config.js` | מוסר לדפדפן את כתובת המסד והמפתח הציבורי ממשתני הסביבה |
| `supabase/schema.sql` | הטבלאות והפרדת הנתונים בין משתמשים |
| `supabase/holidays.sql` | לוח חגים משותף |
| `supabase/functions.sql` | `next_send` ו-`confirm_send`: ההחלטה היומית והרישום |
| `supabase/ratings.sql` | הדירוג של המשתמש מעדכן את ציון המשפט |

סדר ההרצה בעורך ה-SQL של Supabase: `schema.sql`, `holidays.sql`, `functions.sql`, `ratings.sql`.

## אבטחה

- מפתחות סודיים (Supabase service role, Green API, מנוע AI) לא נשמרים בקוד. הם מוגדרים כמשתני סביבה ב-Vercel וכחיבורים ב-Make.
- הדפדפן מקבל רק את המפתח הציבורי. כל משתמש רואה רק את הנתונים שלו, בזכות RLS במסד.
- פונקציות השליחה פתוחות למפתח השירות בלבד.
